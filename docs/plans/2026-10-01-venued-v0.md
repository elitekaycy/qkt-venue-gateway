# qkt-venued v0 — host + paper adapter — implementation plan

**Goal:** a running VGP v1 gateway that the qkt client trades against for real: the host (journal,
idempotent orders, stream with replay, reconciler, kill switch, quotes, bars) and a paper adapter on
Deribit's live public market data, proven by a conformance suite and by qkt's own client end to end.

**Specs:** `docs/design.md` (host and adapters), `docs/vgp-v1-wire.md` (the wire contract; the qkt
copy is authoritative and this one is kept in sync).

**Stack (approved 2026-10-01):** Kotlin 2.1 on JVM 21, Ktor 3 server (Netty, WebSockets),
kotlinx-serialization, OkHttp (venue links), SQLite (xerial JDBC) for the journal, JUnit 5 + AssertJ,
ktlint 1.5. Files ≤ 200 lines (tests ≤ 220), KDoc on public API, decimals as `BigDecimal` from raw
JSON text (never `Double`).

## Verified venue facts (Deribit public API, probed 2026-10-01)

- `public/get_instruments?currency=USDC&kind=option|future`: listings with `instrument_name`,
  `expiration_timestamp`, `strike`, `option_type`, `contract_size`, `tick_size`, `min_trade_amount`.
- `public/ticker?instrument_name=`: `best_bid_price/amount`, `best_ask_price/amount`, `mark_price`,
  `index_price`, (options) `mark_iv`, `underlying_price`, `timestamp`.
- `public/get_tradingview_chart_data?resolution=1`: 1-minute klines (`ticks`, `open`…`volume`); the last
  one is the forming minute and must be dropped.
- `public/get_delivery_prices?index_name=btc_usdc`: daily delivery prices by date.
- Numbers are JSON numbers; they are read as decimal text.

## Tasks

### 1. Scaffold
Gradle build (wrapper 8.14), version catalog, ktlint, `AGENTS.md` (rules, commit identity), README,
`Main.kt` reading a YAML config (listen address, tokens by role, state dir, adapter + settings).
Test: config parses; a missing token or adapter fails with the key named.

### 2. Wire model, auth, read endpoints
VGP DTOs (decimal strings), error envelope, bearer auth with roles (`trader`, `guardian`), and
`/v1/health`, `/v1/account`, `/v1/instruments`, `/v1/positions` served from the adapter.
Tests: Ktor test host; 401 without a token; health carries identity and stream/seq.

### 3. Journal
SQLite (WAL, `BEGIN IMMEDIATE`): `meta` (stream id, kill scopes), `events`, `orders`, `fills`,
`settlements`, `dead_ids`. Append is one transaction with its dedupe row.
Tests: seq increases by one; a duplicate fill appends nothing; reopening keeps the stream; deleting the
file makes a new stream.

### 4. Orders
`POST /v1/orders` (write-ahead, idempotent, 409 on a different body or a dead id, 503 while the venue is
down), `GET /v1/orders`, `GET /v1/orders/{id}` (venue by label when the journal lost it; 404 writes the
id off), `DELETE`, `/v1/deals`, `/v1/settlements`.
Tests: every wire-spec sentence of §3 orders as a test.

### 5. Event stream
`GET /v1/stream?since=` WebSocket: replay `seq > since`, then live; `reset` for a foreign stream or a
`since` older than retention.
Tests: replay after disconnect; reset cases.

### 6. Adapter events and reconciliation
Adapter pushes become journal events; reconcile at start, on venue reconnect and every 60 s (open
orders by label, fills since the last reconciled time with overlap, settlements).
Tests: a fill pushed while no client listens is replayed; a fill missed by the push is found by the
reconciler exactly once.

### 7. Kill switch
`POST /v1/kill` / `release` (guardian role), persisted; submits and modifies refused `423` unless
`reduce_only` and reducing the account; cancels pass.

### 8. Quotes and bars
Quote hub (`GET /v1/quotes`) merging subscriptions, roots expanding to listed options, refresh every
5 s while a quote holds; `GET /v1/bars` paged, closed bars only.

### 9. Paper adapter
Deribit public client (HTTPS JSON-RPC for reads, WebSocket ticker subscriptions), matching at the
touch (market at best bid/ask, limits when the other side reaches them, stops on trigger), netting
positions, cash and equity in USDC, expiry settlement at the delivery price, `label` = client order id.
Tests: recorded public responses as fixtures; matching rules; settlement.

### 10. Real-gateway testing
- Conformance suite run against `qkt-venued` + paper adapter (in CI, against live public data, marked
  so it can be skipped offline).
- From qkt: an opt-in test (`QKT_VGP_URL` set) that verifies the account, subscribes quotes, submits a
  market order and sees it fill and book through the real `GatewayConnector`.

### 11. Deribit adapter (testnet) — after v0
Needs a Deribit testnet account and API key from the user.
